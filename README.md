# Gong Moviees website

All files sit together in the main folder (no subfolders), so they upload easily from any browser.

## Upload / update
1. In your repository click **Add file → Upload files**.
2. Select **all** the files (index.html and every .jpg / .png), drop them in, and click **Commit changes**.
3. The site updates within a minute or two.

## Editing text
Open `index.html` on GitHub, click the pencil icon, change the text, and click **Commit changes**.

## New poster
Upload the image with **Add file → Upload files**, then in `index.html` change that film's `src="..."` to the new file name.
